Header anatomy

Always answers two questions at a glance.

“Am I online?” — the teal header carries a sync pill that turns amber (অফলাইন) when there is no connection; a full-width warning banner repeats the exact reassurance “অফলাইন — সংরক্ষিত, পরে সিংক হবে”.

“How much is waiting?” — the pending count (৭টি অপেক্ষমাণ) sits on the Home section header.

Project name is fixed (one assigned project). Date is a single Bangla date + ritu — never Gregorian on mobile. Bottom nav = 5 items, active in teal. No finance, no settings.

11

Emergency

one-tap জরুরি in critical red · confirmation sheet · offline variant is a safety requirement
Trigger
অক্সিজেন সংকট / মাছ ভেসে উঠছে — সাহায্য চান
Confirmation sheet (offline)

জরুরি সাহায্য পাঠাবেন?

মালিক ও কাছের কর্মীকে এখনই জানানো হবে। শুধু সত্যিকারের জরুরি অবস্থায় ব্যবহার করুন।

অফলাইন — সংযোগ পেলেই সাথে সাথে পাঠানো হবে
Why it's built this way

The trigger is oversized red and lives away from routine tiles so it is unmistakable yet hard to hit by accident. It always needs one confirmation.

If offline, the sheet does not fail — it queues the alert and tells the worker it will fire the instant a connection returns. For an oxygen crash that guarantee matters more than any other message in the app.
