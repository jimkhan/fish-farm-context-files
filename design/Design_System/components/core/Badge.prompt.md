One-line: Generic pill label with a color tone; use for free-form tags. For the fixed domain vocabularies (batch/task/alert/sync status) use StatusBadge or SyncBadge instead.

```jsx
<Badge tone="brand" dot>SPF Golda</Badge>
<Badge tone="warning" icon="alert-triangle">Stale</Badge>
```

Tones: neutral, brand, ok, info, warning, critical. `dot` adds a status dot; `icon` a lucide glyph.
